# AppointmentBooking

I want to make an app for playstore for booking doctors appointment where patients  book doctors appointment via app and doctor gets notification from the app. while booking, patients select pay now and it page should redirect to 'pay via upi' and respective upi like phonepe should open. once payment is done, patients should get appointment confirmation message in the page 'your appointments' where date timing and payment is refecting. To doctors, on 'Your Patients' page it should show patients name who have booked the appoinments , patients address, age of patients and the timing they have booked for. to start the appointment there should be a button on 'Your Patient' page to start video call with respective patients individually.
